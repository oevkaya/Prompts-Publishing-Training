## Common Metadata Mistakes

### AI-Generated Errors to Watch For:

1. **Hallucinated codes**: Fake BISAC, ISBN, or classification numbers
2. **Keyword stuffing**: Unnatural, repetitive keyword usage
3. **Irrelevant categories**: Categories that don't actually fit
4. **Overpromising**: Superlatives and claims that can't be verified
5. **Inconsistent descriptions**: Different info across platforms
6. **Missing required fields**: Incomplete metadata packages
7. **Poor keyword research**: Generic or low-volume search terms
8. **Ignoring platform specs**: Wrong character counts or formatting

### How to Prevent:

- Always verify codes against official sources
- Read descriptions aloud to check naturalness
- Cross-reference with actual competitive titles
- Use keyword research tools (Google Keyword Planner, etc.)
- Follow platform-specific guidelines exactly
- Have humans review all AI-generated metadata
