# Effective Prompting for Publishers

Do you want to discover how generative AI can support ideation, metadata, marketing, and data-driven decisions? This training workshop is designed for publishing professionals and small-to mid-size publishing houses seeking to understand and apply generative AI in their publishing operations. Join our hands-on Prompt-Based AI for Publishers workshop to learn practical prompting techniques and develop prompting strategies to produce book concepts, marketing copy, searchable metadata, and summarised data insights.

**Date and time: 17 February, 2-5pm**
**Format: in person with a hybrid option**

## An introduction to the fundamentals of prompting

The session will demonstrate how large language models (LLMs) can be leveraged effectively to support publishing-related tasks. The training will start with a brief introduction of Gen-AI tools for practical reasons; different prompt strategies and examples will be discussed with specific hands-on examples. The session will focus on practicing various prompts and on developing practical strategies for developing book concepts, marketing copy, and searchable metadata. We will discuss critical issues of editorial quality control and ethical considerations.

For data analysis purposes, certain plug-ins in ChatGPT such as Data Analytics feature and/or Claude (with Code), will be explored with prompting practices. By the end of the session, you’ll leave with the foundational skills for prompting LLMs and some ready-to-use prompt templates.

General structure of the workshop follows tentatively the following key points 

- **Module 1:** Introduction to Gen-AI (LLMs) for Publishing and fundamentals of Prompting (60 minutes)

  - What are LLMs? Overview of ChatGPT, Claude, and other tools
  - Possibilities in publishing: from ideation to production
  - Ethical considerations and limitations
  - Core principles: clarity, context, constraints
  - Prompt patterns: zero-shot, few-shot, chain-of-thought with hands one examples
    
- **Module 2:** Publishing-Specific Applications (60 minutes)
  
  - Book concept development and content ideation
  - Editorial checking and on-purpose usage
  - Marketing copy and promotional content
  - Metadata generation and SEO optimization
    
- **Module 3:** Specific Use-cases, practical templated and tools (60 minutes)

  - How to use custom GPTs; Examples and cfreation of custom GPT via OpenAI
  - Example showcases from Gemini NotebookLLM and others related to publishing
  - ChatGPT Data Analytics feature walkthrough, and other possibilities
  - Further possibilities on open source or local LLMs
  - Discussion about ready-to-use prompt templates and their improvements
  - Q&A and next steps, continued learning resources

### Best Practices

1. Start with clear, specific instructions
2. Use system messages to set consistent behavior
3. Provide examples for complex tasks
4. Request structured outputs for programmatic use
5. Test with small datasets before scaling
6. Document your prompt iterations
